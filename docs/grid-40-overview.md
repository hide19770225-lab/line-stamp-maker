# PR #67: 5列×8段の均等配置と切り抜き確認

5×8への変更時は共通線・列別横線に加え、旧配置の余白・境界診断もリセットする。40コマの共通線を画像全体に等間隔で配置する。既存の2×5処理だけは従来の自動横線検出を維持し、それ以外の配置は加工ボタンでプレビューの位置を暗黙に変更しない。

「余白から自動配置」で共通線と列別の横線をまとめて検出できる。検出失敗時は設定を保持する。「画像全体に均等配置」で余白も含めて復帰できる。全コマのプレビューには実際の整数ピクセル切り抜き座標と出力番号を表示し、タップすると四辺の数値を調整できる。横線は該当列、縦線は全段で共有する。自動配置後の個別調整も加工時に保持する。

「境界を検査」および加工前の検査は、全採用コマの絵柄との重なりを収集する。問題のコマ番号と日本語の辺名を表示し、一覧と元画像で該当辺を赤く描画する。重なりがある場合は画像生成前に停止する。処理ボタンは実際の採用コマ数を表示し、単一画像の5×8全採用時は40個となる。
