# 画素見本を使った表情・ポーズ別のセリフ提案

## 原因と今回の変更

main（9356c15、PR #16）は、左右の青い領域以外を未判定として、あいさつ・外出・就寝などの辞書を順番に割り当てていました。このため、元気な画像に「こんばんは」、怒った画像に「いってきます」が入りました。

今回は **添付実画像の目視ラベルと画素見本の照合** を追加しています。番号・ファイル名・ランダム値で表情を決める処理ではありません。

1. 元画像の画素と透過マスクから、白い残留線を避けて可視領域を求めます。
2. 縦横比を保持した32×32の正規化画素特徴（色と透明度、各4ビット）を抽出します。
3. 添付キャラクター10種類の見本との距離を計算します。距離が大きい場合や、異なるラベルの見本と僅差の場合は判定を棄却します。
4. 近い見本の表情・ポーズに対応した短い日本語候補を選びます。見本照合による推測であることを各画像に表示します。
5. 見本に一致しない場合は従来の限定的な涙特徴検査も使用します。それも該当しない場合は **判定できず・汎用候補** と表示します。汎用候補から時刻・外出・就寝を断定する言葉を除き、画素特徴から安定した開始候補を選びます。

分類用見本のラベルは、この作業で実画像を目視して付けたものです。

## 対応範囲と未実装

これは深層学習の表情認識AIではありません。同じキャラクターの見本に近い画像を照合する方式です。任意の別キャラクター、未知の構図、笑顔だけの違いを一般的に分類する機能は未実装です。見本と同じ姿勢で表情だけ変わった画像を誤判定する可能性があります。閾値は汎用的な精度保証・確率ではありません。必ず一覧で確認できます。

見本は添付ZIPから以前生成した透過済みPNGに由来します。リポジトリには低解像度の派生特徴だけを含め、元画像・アップロードZIPは追加していません。テスト画像も同じ添付素材の派生であり、独立した未知画像での精度評価ではありません。元の一覧画像からの直接認識や、iPhone実機Safari・ホーム画面追加版は未確認です。

任意キャラクターに一般化するには、対象表情の正解付き画像と、適切なモデル・ライセンス・容量・Safari上の性能の検証が必要です。外部の有料APIは追加していません。見本と照合処理は静的JS（合計約46KB）、通信せずブラウザ内で動作します。CSPの connect-src 'none' は維持します。

## 既存操作

通常・一括の読み込み後の自動提案、10個の部分制作、番号別入力、個別編集、承認後の文字合成を維持します。既存セリフは既定で上書きしません。変更したい場合は「登録済みセリフも再提案する」をチェックして再提案します。承認前は完成画像を変えません。重複は使用済み候補を避け、候補を使い切った場合は既存の重複警告で確認できます。任意の40個すべてに無理に違う意味の言葉を割り当てません。

20px余白・日本語の縮小／改行・キャラクターとの重なり回避、プレビュー・PNG・ZIPの共通レンダラーを再利用しています。画像画素、透過マスク、消しゴム、メイン240×240・タブ96×74、ZIP仕様は変更しません。

## 再現方法

見本の再生成（目視確認した01〜10の並びに限る）：

```
node scripts/build-caption-references.cjs /path/to/reviewed-cleaned-pngs
```

実データのブラウザ検証用シート（Python Pillowが必要。元ZIPはローカルのみ）：

```
python3 tests/prepare_reference_images.py /path/to/line-stamps-test-10.zip /tmp/stamp-reference-input
node --test tests/*.test.cjs
NODE_PATH=/tmp/stamp-browser-tests/node_modules STAMP_TEST_URL=http://127.0.0.1:4672 node tests/reference-browser.cjs
PYTHONDONTWRITEBYTECODE=1 python3 tests/verify_suggestions_zip.py /tmp/reference-results
```

テスト用シートは、見本とは異なる縮小・余白・位置にして、元ZIPの09/10の上端線も含む素材から合成します。10個と同じ10ポーズを4回使った40個を検証します。40種類の未知ポーズを検証したものではありません。

## 今回の検証結果

- Nodeの自動テスト59件成功（見本形式、未知・空画像の棄却、曖昧な2見本の混合の棄却、安定性、画素・マスク不変、汎用候補から状況断定を除外、既存テスト）。
- 新規ブラウザテスト：実データ由来の10個と40個（10ポーズ×4）。読み込み後の自動入力、画素から10種類の判定、順番を逆にしても判定不変、再提案の安定性、個別修正、候補の重複なし、承認後の日本語描画、20px余白、文字のはみ出し・重なりなし、元画素・マスク不変、外部通信なし。
- 出力した10個＋メイン・タブ、40個＋メイン・タブのZIPを独立PNGデコーダで検査。プレビュー・生成PNG・ZIP内PNGのRGBA一致、サイズ、透明余白、容量、CRC成功。
- 回帰ブラウザテスト7スクリプト成功：共通自動入力、提案・承認10/40個、20pxレイアウト、部分制作、加工状態とエラー再試行、残留線・消しゴム／取り消し、文字デザイン。回帰では既存の日本語改行、6プリセット×3角度、タッチ文字移動、JSON復元、一括確認、ZIPも確認。
- 実機Safari・ホーム画面追加版と、未知画像への一般的な分類精度は未確認。見本と同じ素材の派生テストであり、未知画像での汎化性能を示すものではありません。
