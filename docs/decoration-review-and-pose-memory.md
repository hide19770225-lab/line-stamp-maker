# 装飾の確認表示とキャラクター別の見本記憶

判定不能時の既定入力と左右反転照合は、追加の [判定確度・装飾グループ改善](pose-confidence-and-decoration-groups.md) で変更しています。

## 調査結果

調査時mainは25806cc（PR #17）。画素解析は実装されていますが、同梱の見本は以前添付された緑色キャラクター10ポーズです。未登録の三毛猫を任意の表情・ポーズへ一般分類するモデルはありません。見本不一致時の理由が汎用的な「未実装」に置き換わっていました。

また、孤立成分検出では幅・高さが5px未満、面積25px未満の装飾などが保護対象から漏れる条件がありました。候補数を「不要な残留線・点」と呼ぶため、確定した不具合と受け取られやすい表示でした。

## 変更内容

### 表情・ポーズ

- 不一致と曖昧さを区別した解析理由を表示。見本がない場合はその旨を明記。
- 一覧で表情を手動選択した後「この端末の見本に記憶」を押すと、その画像の32×32の画素特徴と利用者指定ラベルをブラウザ内に保存。
- 次回の再提案は同梱見本と保存見本を比較し、近い画像に対応するセリフを自動提案。離れた画像やラベルが曖昧な画像は引き続き棄却。
- 笑顔、怒り、睡眠、驚き、泣く、困る、手を振る、ハートなどを利用者ラベルとして指定可能。**AIによる意味理解・汎用表情認識ではありません。最初の見本には人による表情指定が必要です。**
- 保存は明示操作のみ、最大40件。このブラウザのlocalStorageを使用し、画像送信なし。元画像そのものは保存せず、低解像度の派生画素特徴を保存。
- 見本だけを解除でき、画像・セリフは変更しません。既存のプロジェクトJSON形式は変更せず、保存見本はJSONや別端末に移行されません。Safariのデータ削除・容量制限などで失われる場合があります。
- 未判定には既存の汎用候補表示を維持。汎用候補は画像の意味から決めたものではありません。

### 残留成分

- 色付きの小さな孤立成分、コンパクトな小成分を、外周境界から離れている場合に装飾・詳細候補として保護。ハート・星・汗・怒りマークであり得る成分を安易に削除候補へ入れません。
- 意味を識別する装飾認識AIではありません。必要な装飾を優先し、不要な点も保護側へ入る可能性があります。必要な場合は個別編集の消しゴムで修正できます。
- 未保護の成分は「孤立成分の要確認（異常は未確定）」と表示。PNG寸法・透明度などの確定した検査エラーとは分離。
- 一括確認に検出位置の表示切り替えを追加。橙が要確認、緑が装飾・詳細候補。別のオーバーレイCanvasで描き、プレビュー本体・完成PNG・ZIPの画素を変えません。
- 装飾候補数だけでは要確認・エラーにせず、透過の目視確認は別途必要。外周付近・判定できない成分は要確認のまま残します。
- 従来の狭い条件による上端線自動除去は変更せず、今回の検査で新たに自動削除する処理は追加していません。

## 実画像の確認状況

今回の三毛猫の元画像と出力ZIPはアップロード待ちです。作業環境で確認できた添付は以前の緑色キャラクターのZIPのみです。したがって **三毛猫02のハート、03の親指、08の怒り、09の睡眠、10のハート抱えの実画像検証は未実施** です。合成画像や以前の素材の検証結果を、今回の三毛猫で確認した結果とは扱いません。

任意キャラクターの表情・ポーズを自動で意味認識する機能は未実装です。一般化可能なモデルの選定、配布ライセンス、正解付き画像での精度評価、Safariの容量・メモリ・速度の検証が必要です。有料APIやサーバーは追加していません。iPhone実機Safari・ホーム画面追加版は未確認です。
