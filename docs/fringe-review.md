# PR #67：外周の白縁の軽減

暗い輪郭の白背景混入を軽減。**白縁の完全除去は未達**。明るい文字・ハート・星・涙・煙などの縁は、本来の装飾との区別が曖昧なため残した。全10枚を完全解決とは判定しない。

比較基準は直前のPR先端 `a7fbe457986099289816cb1c7a7b34f0ee2e95f2`。同じ元一覧PNG（916×1717、SHA-256 `31f7b0a2f675a3bc67e964363a2702f0e7260388a9b2c81ae620065510910291`）、自動背景判定、許容差24、2列×5段、余白0で再生成。今回、分割位置と各コマの寸法は修正前後で同一。

## 変更

外周連結背景の判定・輪郭の閉鎖による内部の白の保護は維持。外側背景へ4近傍で接する元の1層だけで、近傍2pxに濃い不透明な輪郭があり、背景との線形混合で説明できる中性色を補正する。局所色からアルファを推定し、RGBから背景成分を逆算する。暗い画素、背景とほぼ同色の白、色付き画素、元から半透明の画素、内部はこの補正の対象外。

侵食の反復や一律の白の透明化はしない。補正対象もアルファ0にはせず部分被覆として保持する。参照するマスクは処理開始時のスナップショットで、走査順に依存した削り込みはしない。番号・固定座標・コマ別例外なし。元RGBAは変更せず疎なRGB補正を通常描画で適用する。手動マスクが自動マスクと異なる画素は手動操作を優先する。プロジェクト再生成時にも同じ元画像から補正を再計算する。

## 検査と限界

- 17単体テストファイル成功。新規検査は白背景への再合成が元の境界色を誤差1以内で再現すること、RGB汚染の軽減、元画像不変、内部白・陰影・濃い細線・元から半透明・推定不能な淡色装飾の保持。
- 実10枚では、前版で保持していた白（RGB最小値231以上）と濃い画素（RGB最大値75以下）のアルファ不変。色差24超の既存検査対象もアルファ不変。新たにアルファ0になる画素は全10枚で0。これは意味的な全装飾の正解マスクの証明ではない。
- 全10枚のネイティブPNGと実アプリ370×320 PNGを再生成。ページエラーなし。ZIPの10枚は通常描画PNGとバイト一致。12エントリのCRC正常。
- 元一覧と比較画像を目視確認し、03と09を重点拡大。実機Safariは未検証。
